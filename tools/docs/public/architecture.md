## 输入与动作

`observations` 声明各项数据源、宽度、缩放和旋转变换；`inputs` 绑定模型具名输入，`states` 绑定独立隐藏状态，`actions` 指定参考姿态、通道映射、模式、缩放和限幅。向量顺序与关节名称应明确，不能通过形状相同推断语义相同。

新增模型执行后端实现 `ModelExecutor`；新观测算法扩展 `ObservationRegistry`。新机器人在已有观测和动作模式可覆盖时，只需配置与资产，不增加按机器人名称判断的 C++ 分支。

## 控制、遥测和图像

三条通道独立管理。页面切换复用会话；图表有界缓冲和绘图节流，暂停显示不停止采集。速度命令依赖后端超时保护；前端失焦或断连归零，重连不恢复历史非零速度。

网页画面来自 Gazebo 原生相机和 ROS 图像桥接，并非嵌入原生窗口。JPEG 流复用最新帧，避免为每个浏览器请求重复渲染。Gazebo 端仍需 OpenGL / DISPLAY 上下文。环绕、平移、缩放、跟随和总览由独立渲染适配层处理。

MP4 使用真实相机帧与服务端 FFmpeg 编码；停止录制后等待编码完成。CSV 记录与图表、图像和视频独立。没有真实连接的状态显示未接入或未启动，不生成假遥测。
