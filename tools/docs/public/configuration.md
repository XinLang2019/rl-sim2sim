# 配置与网页参数

[返回 README](../../../README.md)

## 三类配置

- `configs/legged/*.yaml`、`configs/wheel/*.yaml`：一个机器人一份主配置。`robot` 管理资产和关节顺序，`control` 管理启动与过渡控制，`policies` 管理策略输入输出契约。
- `configs/simulation.yaml`：后端、地形和录制数据源等共享能力。
- `configs/task.yaml`：空任务模板。网页根据当前机器人、策略文件、地形与出生位姿补齐，只作用于本次任务。

模型放在 `policies/{legged,wheel}/机器人/策略目录/`；网页只列出所选机器人对应的文件。选择具体 ONNX 后仍需关联部署契约，模型文件本身不能完整描述关节顺序、观测语义、参考姿态或动作缩放。

示例配置见 [Go2W](../../../configs/wheel/go2w.yaml)和 [A1](../../../configs/legged/a1.yaml)。模型接口校验成功不等于机器人已完成闭环验证。`blocked` 或 `unconfigured` 的条目需先补齐契约，不应直接修改状态冒充兼容。

## 控制器重载

停止控制器并等待确认，再选择同一机器人的兼容策略或修改参数。点击应用，后台校验本次文件、关节映射及周期；成功后启动控制器、站立、启用策略。这个流程保留 Gazebo 进程和仿真时钟。

策略 PD 按腿关节和轮关节分别批量设置；参考关节位置按关节顺序填写。轮速缩放只影响速度动作通道。`policy_dt = control_dt × decimation`，物理步长与控制周期必须相容。单位为 m、rad、s；deg/rad 切换只改变网页显示。

更换机器人、World 或物理参数需要新任务。模型位姿复位调用 Gazebo 模型状态服务，仅改变位置、姿态和模型速度，不重置仿真时钟或控制状态。

## 数据与输出

CSV 录包保存到服务端 `tools/runs/<task-id>/`，主动录制的 MP4 保存到 `videos/`。新任务成功生成后，任务输出保留最近五次；长期数据请提前备份。网页图表暂停、缩放、切页与录包独立。

加载本地或已完成的服务端 CSV 后可拖拽信号到 Tab，拆分画布，缩放、平移或播放数据。回放只分析数据，不向机器人发送控制命令。缺失数据保留缺口，仿真重置或时间跳变会分段。
